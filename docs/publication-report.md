# 공개 파일 검토 보고서

## 작업 범위와 게시 상태

이 폴더는 기존 프로젝트를 복사하고 데이터를 합성으로 대체한 버전입니다. 원본 코드 자체가 포함되므로 **독립 데모와 달리 원본 소스의 공개 허가가 반드시 필요합니다.** 검토 대상은 이 폴더의 매니페스트에 명시된 파일뿐입니다. 원본 저장소와 이전 독립 데모는 수정·업로드 대상이 아닙니다. 게시 시에는 새 Private 저장소에서 시작해 원격 파일 일치 검증 후 Public으로 전환하는 절차를 따릅니다. 기존 운영 서비스와 배포 설정은 변경하지 않습니다.

## 포함·제외

기존 환경 예시 파일을 제외한 추적 파일 34개를 복사했습니다. 인물·기관 정보가 있는 데이터 파일은 전체 합성 생성으로 교체했습니다. 자료는 파일명·유형 등 메타데이터뿐이며 실제 PDF·업무 문서는 없습니다.

원본별 동일/수정 파일과 새 파일 전체 목록은 [파일 매니페스트](source-manifest.json)에 기록합니다. README·기술/변경 문서·검사기·테스트·합성 캡처 4개를 추가했습니다.

제외: 원본 `.git/`·Git 객체/로그·환경파일·API 키·실제 업무 문서·DB·백업. `node_modules/`, `dist/`, `test-results/`, `playwright-report/`, `.local/`는 로컬 생성물로 업로드 대상이 아닙니다. 폴더 전체 ZIP 공유 대신 매니페스트의 검토 목록을 사용해야 합니다.

## 데이터와 외부 통신

- 기관 96곳·평가위원 12명·작가·담당자·배정 관계·프로그램·날짜·평가·자료 목록은 독립 생성 합성입니다. 원본 명칭을 가린 기록이 아닙니다.
- 연락처는 빈 전화번호와 예약 도메인 `example.invalid`를 사용합니다. 실제 전화를 걸거나 메일을 발송하지 않습니다.
- `arco_portfolio_synthetic_v1_*`만 읽고 씁니다. 원본 저장 키를 읽거나 삭제하지 않습니다.
- 합성 기관·인물 식별자가 맞지 않거나 저장 형태가 손상된 경우 초기 합성 목록으로 복구합니다.
- AI API 경로는 요청 본문을 응답에 반영하거나 공급자로 전달하지 않고 정해진 합성 응답을 반환합니다. 실제 키를 설정해도 Gemini 호출이 실행되지 않습니다.
- 기존 Excel 가져오기·파일 선택 UI를 유지했으므로 사용자가 실제 자료를 입력하지 않아야 합니다. 임의의 사용자 입력 전체에 대한 자동 비식별화를 제공하는 도구는 아닙니다.

## 검증 기록

환경: Windows·Node.js 22.18.0. 타입 검사와 원본 방식의 Vite/Express 빌드를 실행했습니다. 큰 청크 경고는 원본 구조를 유지한 결과로 남깁니다.

최종 테스트·공개 파일 검사 수치는 완료 보고에서 확인합니다. 원본 명칭 잔존 대조는 값 자체를 저장/출력하지 않고 실시합니다. 민감정보 패턴 검사만으로 권한·저작권·개인정보 문제의 부재를 보장하지 않습니다.
