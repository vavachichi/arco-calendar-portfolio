# 기존 프로젝트 보존 및 최소 수정

## 보존 원칙

새 UI나 새 업무 플랫폼을 개발하지 않았습니다. 원본의 추적 파일을 복사하되 환경파일과 Git 이력은 제외했습니다. 기존 컴포넌트·타입·스타일·캘린더·예약 핸들러·평가표·Excel/CSV/ICS 로직·AI 화면을 보존합니다. 실제 동일 파일은 [해시 목록](source-manifest.json)으로 확인합니다.

## 기존 파일 변경 범위

| 파일 | 변경 이유 |
|---|---|
| `src/data/mockData.ts` | 실명·실기관 목록을 제거하고 12명·96곳·1인 8곳 구조의 합성 인물·기관·배정·프로그램·자료·제안·평가로 교체 |
| `src/App.tsx` | 기존 `arko_*` 키와 실명 기반 초기값 판정을 제거하고 전용 키·합성 식별자 검사로 초기화. JSX·업무 핸들러는 유지 |
| `server.ts` | 기존 AI 경로 3개를 안전한 예시 응답으로 교체. 원본 프롬프트·공급자 클라이언트·환경파일 로딩 제외. 로컬 127.0.0.1:5190 사용 |
| `src/utils/calendarUtils.ts` | 누락된 `isSpecialtyMatch` 반환 플래그 정의. 기존 매칭 점수 가중치는 변경하지 않음 |
| `src/components/EvaluatorPortal.tsx` | `location → locationRoom`, `expectedAttendees → maxParticipants`, `fileType → type`의 타입 불일치 3곳 수정. 마크업·클래스 유지 |
| `src/components/ExcelBatchProgramImport.tsx` | 샘플 장소 필드명을 `locationRoom`으로 일치시키고 빈 장르를 해당 작가의 장르로 대체 |
| `package.json` | React 타입 정의·Playwright 및 검사 명령 추가. 기존 앱 런타임 의존성 유지 |
| `.gitignore` | 로컬 테스트·로그·비밀파일·DB·실제 문서 제외 규칙 추가 |

나머지 원본 파일은 바이트 단위 동일 여부를 검증합니다. `src/index.css`, `src/types.ts`, `vite.config.ts`, 캘린더·관리자·로그인·기관·평가표·Gemini 도우미 등의 디자인을 재작성하지 않았습니다.

## 추가 파일의 역할

`src/data/portfolioStorage.ts`는 저장 키 분리와 합성 식별자 검사만 담당합니다. `portfolio-api.ts`는 기존 UI의 응답 계약에 맞춘 예시입니다. 테스트 하네스는 원본 AI 컴포넌트·ICS 함수를 검증하기 위한 테스트 전용이며 앱 번들에서 가져오지 않습니다.

## 원본에서 확인한 제한 — 새 기능으로 보완하지 않음

- `handleAcceptProposal`과 `handleToggleAvailableDate`는 App에 있고 자식으로 전달되지만, 해당 자식의 렌더링된 UI에서 호출되지 않습니다. 수락·가용일 변경을 완성된 사용자 흐름으로 주장하지 않습니다.
- `AIAssistantModal`과 열기 상태는 있으나 관리자 화면의 열기 콜백에 실제 버튼이 연결되지 않았습니다. 도우미는 테스트 하네스에서 원본 컴포넌트를 직접 마운트해 응답 표시를 검증합니다.
- `exportToICS`는 유지되지만 기존 화면에서 호출 버튼이 연결되지 않았습니다. 생성 함수의 다운로드를 테스트 하네스에서 검증합니다.
- 프로그램 추가 모달은 최초 마운트 시 선택된 기관을 유지하므로 기관을 명시적으로 선택해야 합니다. 이번 테스트도 기존 기관 선택 UI를 사용합니다.
- 원본 로그인은 클라이언트 검사이며 서버 권한 검증이 아닙니다. 자료 선택은 메타데이터 등록이며 본문 저장이 아닙니다.
- 기존 평가 상태 표시·카운트 기준과 예약 충돌 정책은 유지했습니다. 신규 정책·동시성 제어·보안 인증을 추가하지 않았습니다.
- 빌드의 큰 청크 경고는 유지했습니다. 디자인·번들 구조를 바꾸는 최적화는 수행하지 않았습니다.

## 검증 구분

단위 검증: 합성 데이터 수·배정·참조, 캘린더·매칭, 전용 저장 키·손상 복구, AI 응답의 입력 비반영.

브라우저 검증: 기존 로그인·예약·변경·취소, 기관 프로그램 등록·자료 추가/삭제, 제안 생성, 평가서 저장, CSV 다운로드, 테스트 하네스의 ICS·AI 3종 응답, 기존 화면 4장 캡처. 브라우저에서 로컬 호스트 외 요청은 차단합니다.

테스트·안전화·최소 오류 수정은 이번 포트폴리오 복사본 작업이며 원본에서 이미 검증되었던 결과로 설명하지 않습니다.

## 추가 데이터 예시 치환

- `src/components/BatchDataImportModal.tsx`: 원본 안내용 placeholder에 있던 기관·인물·연락처 예시를 가상 평가위원·가상 모임·example.invalid 이메일·빈 전화번호로 교체했습니다. 마크업·클래스·입력 처리는 바꾸지 않았습니다.
- `src/utils/excelImportUtils.ts`: 전화번호가 없을 때 넣던 번호 형태의 기본값을 빈 문자열로 교체했습니다. 실제 연락처나 연결 가능한 번호를 합성 초기값에 포함하지 않습니다.
